# 数组算法总结：二分查找 vs. 双指针法

在处理数组类题目时，**二分查找**和**双指针**是最基础且最高频的两种优化策略。

---

## 一、 二分查找 (Binary Search)

### 1. 使用前提
*   **有序性**：数组必须是有序的（升序或降序）。
*   **查找目标**：在数组中寻找一个特定值，或者寻找满足某个条件的第一个/最后一个位置。
*   **复杂度目标**：希望将时间复杂度从 $O(n)$ 降低到 **$O(\log n)$**。

### 2. 核心难点：边界处理
*   **左闭右闭 `[left, right]`**: `while (left <= right)`，更新时 `right = middle - 1`。
*   **左闭右开 `[left, right)`**: `while (left < right)`，更新时 `right = middle`。

### 3. 常见题型
*   [704. 二分查找](https://leetcode.cn/problems/binary-search/)：标准模板。
*   [35. 搜索插入位置](https://leetcode.cn/problems/search-insert-position/)：寻找边界。
*   [34. 寻找第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)：处理重复元素。
*   [69. x 的平方根](https://leetcode.cn/problems/sqrtx/)：数学逻辑的二分。

---

## 二、 双指针法 (Two Pointers)

### 1. 核心价值
通过两个指针的协作，**将嵌套循环的 $O(n^2)$ 复杂度降低为 $O(n)$**。通常能将空间复杂度控制在 $O(1)$。

### 2. 三大流派

#### ① 快慢指针 (同向移动)
*   **操作**：两个指针从起点出发。`fast` 寻找目标，`slow` 指向待更新位置。
*   **场景**：**原地修改数组**、删除特定元素。
*   **经典**：[27. 移除元素](https://leetcode.cn/problems/remove-element/)、[283. 移动零](https://leetcode.cn/problems/move-zeroes/)、[26. 删除重复项](https://leetcode.cn/problems/remove-duplicates-from-sorted-array/)。

#### ② 对撞指针 (头尾移动)
*   **操作**：两个指针分别从数组的首、尾向中间汇合。
*   **场景**：**有序**数组中寻找两端特征、容器盛水、数组反转。
*   **经典**：[977. 有序数组的平方](https://leetcode.cn/problems/squares-of-a-sorted-array/)、[167. 两数之和 II](https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/)。

#### ③ 逆向双指针 (从后往前)
*   **操作**：为了解决“覆盖”问题或“后方影响前方”的逻辑。
*   **场景**：字符串退格处理、合并两个有序数组。
*   **经典**：[844. 比较含退格的字符串](https://leetcode.cn/problems/backspace-string-compare/)。

---

## 三、 滑动窗口 (Sliding Window)

### 1. 核心思想
滑动窗口本质上也是**双指针**的一种（快慢指针的进阶版）。它通过不断调节子序列的**起始位置**和**终止位置**，从而将 $O(n^2)$ 的暴利解法降低到 **$O(n)$**。

### 2. 滑动窗口的三要素
*   **窗口内的内容**：我们要维护的子数组（如：和大于等于 target 的长度）。
*   **起始位置 `start`**：当窗口内容满足条件时，开始向右移动以缩小窗口，寻找“最优解”。
*   **结束位置 `end`**：窗口的扩张动力，通常是 `for` 循环中的变量。

### 3. 滑动窗口的通用模板
```cpp
int start = 0;
int sum = 0;
int result = INT_MAX;
for (int end = 0; nend < nums.size(); end++) {
    sum += nums[ed]; // 1. 进窗：扩张窗口
    while (sum >= target) { // 2. 达到条件：维持或缩小窗口
        result = min(result, end - start + 1); // 3. 记录/更新结果
        sum -= nums[start++]; // 4. 出窗：移动起始位置
    }
}
```

### 4. 常见题型
*   [209. 长度最小的子数组](https://leetcode.cn/problems/minimum-size-subarray-sum/)：基础入门。
*   [904. 水果成篮](https://leetcode.cn/problems/fruit-into-baskets/)：变换条件的滑动窗口。
*   [76. 最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/)：最难的滑动窗口（困难题）。

## 四、 方法选择指南

| 题目特征 | 推荐方法 | 关键点 |
| :--- | :--- | :--- |
| **有序数组** + **寻找特定位置/值** | **二分查找** | 确定好循环不变量（区间定义） |
| **原地操作** + **过滤/删除某些元素** | **快慢指针** | `fast` 找什么？`slow` 停在哪？ |
| **有序数组** + **求子项组合/处理两端** | **对撞指针** | 哪一端的平方或和更大？ |
| **结果由后面决定** + **要求 $O(1)$ 空间** | **逆向双指针** | 从后往前遍历，避开未知干扰 |
| **连续子部分** + **求最优（最小/最大）** | **滑动窗口** | `while` 循环里如何控制窗口缩小 |

---

> **一句话总结**：
> 有序求值找二分（$\log n$），原地修改快慢跟（$n$）；有序两端选对撞，退格合并逆向推；**连续子项找最优，滑动窗口最高效。**

## 五、 滑动窗口详细操作步骤（续）

基于LeetCode 76题（最小覆盖子串）的实现，这里详细拆解滑动窗口的每一步，帮助初学者理解。

### 1. 初始化窗口和变量
- 定义左右指针：`int left = 0;`（窗口左边界），右指针在for循环中。
- 初始化窗口状态：用 `unordered_map<char, int> window;` 记录窗口内字符数量；`unordered_map<char, int> need;` 记录t中字符需求。
- 初始化结果：`int minLen = INT_MAX; int start = 0;`（最小长度和起始位置）。
- 初始化计数：`int count = 0;`（覆盖的字符种类数）。

### 2. 扩展右指针
- `for (int right = 0; right < s.size(); ++right)`：
  - 进窗：`char c = s[right]; window[c]++;`
  - 检查覆盖：`if (need.count(c) && window[c] == need[c]) count++;`（只有t中的字符，且数量正好满足时，count++）。

### 3. 收缩左指针（当条件满足时）
- `while (count == need.size() && left <= right)`：
  - 更新结果：`if (right - left + 1 < minLen) { minLen = right - left + 1; start = left; }`
  - 出窗：`char d = s[left]; window[d]--;`
  - 检查影响：`if (need.count(d) && window[d] < need[d]) count--;`（移除后数量不足，count--）。
  - 左移：`left++;`

### 4. 返回结果
- `if (minLen == INT_MAX) return "";`
- `return s.substr(start, minLen);`

### 注意点
- **边界处理**：用 `left <= right` 确保长度1的窗口被处理。
- **条件检查**：扩展时必须 `need.count(c)`，避免无关字符影响count。
- **适用扩展**：这个模板可用于水果成篮、长度最小子数组等题，只需调整条件和状态记录。

通过这个步骤，我们将O(n^2)降低到O(n)，高效解决连续子串问题！

## 六、 滑动窗口通用总结与模板

### 通用总结
- **适用场景**：连续子数组/子串问题，如找最小/最大长度、覆盖条件、和大于等于目标等。数组/字符串无序也可。
- **优势**：时间O(n)，空间O(1)或O(k)（k为字符种类数）。比暴力法高效。
- **核心思想**：右指针扩展窗口，左指针收缩，动态维护窗口状态。
- **关键**：定义“窗口状态”（如sum、count、map）和“满足条件”（如sum >= target、count == need.size()）。
- **变体**：固定窗口（窗口大小固定）、动态窗口（大小变化）。

### 通用代码模板
```cpp
// 假设nums是数组，target是条件（如最小和）
int left = 0;
int result = INT_MAX;  // 或INT_MIN，根据题调整
// 窗口状态变量，如sum = 0; 或map window;
int sum = 0;  // 示例：求和

for (int right = 0; right < nums.size(); ++right) {
    // 1. 扩展窗口：更新状态
    sum += nums[right];
    
    // 2. 收缩窗口：当满足条件时，缩小并更新结果
    while (满足条件，如 sum >= target) {  // 条件根据题调整
        result = min(result, right - left + 1);  // 更新结果
        sum -= nums[left];  // 出窗
        left++;  // 左移
    }
}

return result;  // 或根据题返回
```

### 模板应用示例
- **长度最小子数组（和 >= target）**：用sum，while(sum >= target)。
- **水果成篮**：用map记录种类，while(种类 > 2)。
- **最小覆盖子串**：用两个map，while(count == need.size())。

这个模板灵活，改改条件就能用！
